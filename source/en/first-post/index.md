## The Blog Is Live 🎉

This is my first blog post, built with the **Hugo + Paper theme** and automatically compiled and deployed by **GitHub Actions**.

### Workflow

1. Write Markdown locally
2. Push to GitHub
3. Actions automatically runs `hugo --minify`
4. Deploy to GitHub Pages
