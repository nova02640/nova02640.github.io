## 博客开张 🎉

这是我的第一篇博客文章，通过 **Hugo + Paper 主题** 搭建，由 **GitHub Actions** 自动编译部署。

### 工作流程

1. 本地写 Markdown
2. 推送 GitHub
3. Actions 自动 `hugo --minify`
4. 部署到 GitHub Pages
